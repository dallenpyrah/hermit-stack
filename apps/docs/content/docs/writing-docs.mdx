This site is `apps/docs`: Fumadocs on Next.js, built as a static export. It is the only place in the repo where React and Tailwind are allowed, and nothing may depend on it.

## Add a page

1. Write an `.mdx` file in `apps/docs/content/docs/`. Give it a `title` and a `description` in the front matter.
2. Add its file name, without `.mdx`, to `pages` in `content/docs/meta.json`. That list is the sidebar's order.
3. Preview it with `mise exec -- pnpm --filter @repo/docs dev` at `http://localhost:3000/docs`.

Search covers every page with no setup. The build writes the search index to `/api/search`, and the browser downloads it and searches it, so the site needs no server.

## Code blocks are typechecked

Every code block tagged `ts` or `typescript` is typechecked as part of `pnpm check`, so an example cannot go stale without the check failing. When the kernel renames `spanName`, the examples that use it fail too.

The `typecheck` task of `apps/docs` does it in two steps:

1. `src/fences/code-fences.cli.ts` writes each block to `.fences/<page>/line-<n>.ts`, where `n` is the page line the block's code starts on.
2. `effect-tsgo` typechecks those files with `tsconfig.fences.json`, which uses the repo's base config. Examples meet the same Effect diagnostics as the rest of the repo.

Each block is its own module, so it states its own imports. It can import anything `apps/docs` depends on, such as `effect` and `@repo/kernel`. To use another package in an example, add it to the `devDependencies` of `apps/docs`.

Each written file keeps the page's line numbers, so an error points at the page:

```text
.fences/conventions/line-59.ts(71,34): error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.
```

This is what the check printed when `withTax(0.08)` on the conventions page was changed to `withTax("0.08")`: the block starts on line 59, and the error is on line 71, column 34 of `content/docs/conventions.mdx`.

To show code that should not be typechecked, such as a shell command or a fragment, tag the block with another language: `sh`, `json` or `text`.

## Check it

```sh
mise exec -- pnpm exec turbo run typecheck build --filter=@repo/docs
```

`build` runs `next build` and writes the site to `apps/docs/out/`.
