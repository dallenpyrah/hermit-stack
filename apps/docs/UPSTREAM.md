# Upstream

The site shell is adapted from the Akter docs app, `apps/docs` in `rika-labs/akter` at commit `6af552a3b1b6659a272ab5ecf8f90385086818ea` (2026-11-13), under Apache-2.0. It was copied, not imported, and this repo owns the copy. The pages in `content/` are written here; none came from Akter.

## Copied and adapted

Every copied file had the `ak-` class prefix renamed to `hs-`, and its imports moved from Akter's `#content/` and `#components/` maps to `#src/content/` and `#src/components/`.

## Written here

- `assets/favicon.svg`: the hermitstack shell-spiral mark, also the sidebar logo.
- `src/components/landing/hero-art.view.tsx`: new art, one application chip wired to four targets. It keeps Akter's grain filter and trace style.
- `src/fences/`: the code-block typecheck, from this app's first version.
- Every page in `content/`.

## Left out

varlock, portless, the Bun scripts, the Wrangler deploy and Cloudflare hosting files, the reproducible-build check, the cloud API reference pages and the product switcher.

To take a later upstream change, diff Akter's `apps/docs` from the commit above to its new head and apply what fits here, then update the commit in this file.
